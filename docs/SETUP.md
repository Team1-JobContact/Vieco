
# Hướng dẫn cài đặt Vieco

## 1. Yêu cầu
- Git
- Trình soạn thảo mã nguồn (ví dụ VS Code)
- Công cụ chạy dự án: chờ xác nhận tech stack
- Hệ quản trị CSDL: chờ xác nhận

## 2. Clone repository
git clone <REPOSITORY_URL>
cd <TEN_THU_MUC_REPOSITORY>

## 3. Cài đặt dependencies
Chưa có source code. Sẽ bổ sung lệnh cài đặt
sau khi nhóm thống nhất công nghệ.

## 4. Cấu hình môi trường
Chưa xác định các biến môi trường.
Không commit file .env chứa thông tin bí mật.

## 5. Chạy dự án
Chưa thể chạy vì repository chưa có source code.

## 6. Cập nhật
Tài liệu sẽ được hoàn thiện khi frontend,
backend và database được tích hợp.
