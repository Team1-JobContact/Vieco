# Nguồn ảnh demo

Ảnh trong thư mục này chỉ dùng cho dữ liệu demo của Vieco (`python -m src.seeds.demo_media`).
Ảnh đã được cắt và nén lại; logo là nhãn hiệu của doanh nghiệp tương ứng.
Ảnh giấy phép CC BY / CC BY-SA phải giữ ghi nguồn tác giả khi hiển thị công khai.
